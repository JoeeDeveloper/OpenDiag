# Clean-room policy

OpenDiag is an independent project. Contributors must not:

- copy, scrape or redistribute Ross-Tech label files (.lbl), VCDS binaries, or ODIS data;
- contribute data derived by reading or converting those files;
- ship algorithms that bypass immobiliser, odometer or tuning protection.

Contributors may:

- implement from public specifications (see `sources.md`);
- contribute data they captured themselves from their own vehicles, with a `captured_on` provenance field;
- write original descriptions of modules, DTCs and measuring blocks.

If you have seen proprietary label data and are unsure whether your contribution is affected, say so in the PR and a maintainer will advise.
